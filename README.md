# Qala & Kesene — ортағасырлық сәулет мұрасының 3D платформасы

**Тақырып:** Ортағасырлық қала сәулеті мен қазіргі архитектураның сабақтастығы: көне ескерткіштерді цифрлық технологиялар арқылы сақтау.

Сайт Қазақстанның 12 ортағасырлық қаласы мен 18 кесенесін 3D карталарда көрсетеді. Әр нысанның жеке беті бар, онда параметрлік 3D моделі берілген. Деректер «Қазақстанның орта ғасырлық қалалары мен кесенелері» тарихи-географиялық анықтамалығынан алынған.

## Беттер

| Бет | Мазмұны |
|---|---|
| `index.html` | Басты бет. Hero бөлімінде Ясауи кесенесінің 3D LiDAR сканерленуі көрсетіледі. Сонымен қатар сабақтастық мысалдары, цифрлық тізбек, «ArchHeritage VR» концепті (кірпіштен шыныға 3D морфинг) және слайдтар бар. |
| `cities.html` | Қалалардың 3D картасы: жер бедері, спутник, Ұлы Жібек жолы, саяхат режимі, хронология және қала карточкалары. |
| `mausoleums.html` | Кесенелердің 3D картасы және сәулеттік типтер бойынша топтастыру. |
| `object.html?id=…` | Нысан беті. Мұнда 3D модель, нысан туралы деректер, шағын 3D карта, автоматты құрылатын цифрлық сақтау жоспары, жақын нысандар (км бойынша) және алдыңғы/келесі нысанға өту бар. |
| `registry.html` | ГИС тізілімі: іздеу, сүзу, сұрыптау және GeoJSON/CSV экспорты. |

## 3D модельдер

Модельдер дайын файлдан жүктелмейді. Олар `js/data/heritage.js` ішіндегі параметрлерден браузерде жиналады (Three.js):

- **Кесенелер** алты типке бөлінеді: порталды-күмбезді, күмбезді шаршы, шатырлы күмбезді (Бабаджа хатун), ұзынша мазар (Үкаша ата), киіз үй пішінді тас кесене (Домбауыл) және қобыз пішінді мемориал (Қорқыт ата).
- **Қалалар** келесі элементтерден құралады: төбе, шахристан қабырғалары мен мұнаралары, қақпалар, цитадель, көшелер мен үйлер, жұма мешіті мен мұнара, базар, рабад және сыртқы қорған. Кейбір қалаларда өзен, кәріз және таулар қосылады.
- **Режимдер:**
  - «Тарихи» — нысанның тарихи көрінісі;
  - «Қазіргі күй» — тек қалаларда: қабырғалар мен үйлердің бүгінгі сақталған биіктігі;
  - «Цифрлық егіз» — жүктеме мен қауіп картасы және датчиктер;
  - «LiDAR» — шамамен 90 000 нүктеден тұратын бұлттың сканерлену анимациясы.

> Модельдер — схемалық реконструкция. Олар нақты археологиялық өлшемдерді емес, сәулеттік типті көрсетеді.

## Құрылымы

```
index.html, cities.html, mausoleums.html, object.html, registry.html
css/main.css               — бірыңғай стиль жүйесі (жарық/қараңғы режим)
js/data/heritage.js        — деректер қоры, қашықтық есептеу, сақтау жоспарының ережелері
js/core/layout.js          — ортақ header/footer, тақырып, мобильді мәзір
js/map/heritageMap.js      — 3D карта класы (MapLibre GL), хронология
js/three/viewer.js         — 3D көрермен: режимдер, LiDAR, цифрлық егіз, морфинг
js/three/mausoleum.js      — кесенелердің параметрлік құрастырушысы
js/three/city.js           — қалалардың параметрлік құрастырушысы
js/three/materials.js      — процедуралық текстуралар (кірпіш, терракота, глазурь, тас)
js/three/geom.js           — геометриялық көмекшілер
js/pages/*.js              — әр беттің логикасы
assets/img/                — жоба слайдтары
```

## Жаңа нысан қосу

`js/data/heritage.js` ішіндегі `CITIES` немесе `MAUSOLEUMS` массивіне жаңа жазба қосыңыз. Жазбада `id`, `name`, `era`, `s`, `lat`, `lon`, `region`, `desc` өрістері және `model` параметрлері болуы керек. Нысан картада, тізілімде және өз 3D бетінде автоматты түрде пайда болады.

## Іске қосу

Сайт статикалық, оны құрастыру (build) қажет емес. ES модульдері қолданылатындықтан, сайтты `file://` арқылы емес, сервер арқылы ашу керек:

```bash
python3 -m http.server 8000
```

Содан кейін http://localhost:8000 ашыңыз. Сайтты GitHub Pages арқылы жариялау үшін: Settings → Pages → `main` / root.
