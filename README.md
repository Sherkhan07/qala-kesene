# Qala & Kesene — ортағасырлық сәулет мұрасының 3D картасы

**Тақырып:** Ортағасырлық қала сәулеті мен қазіргі архитектураның сабақтастығы: көне ескерткіштерді цифрлық технологиялар арқылы сақтау.

Бұл сайт Қазақстанның ортағасырлық қалалары мен кесенелерін интерактивті 3D карталар мен 3D модель арқылы көрсетеді. Деректер «Қазақстанның орта ғасырлық қалалары мен кесенелері» тарихи-географиялық анықтамалығынан алынған.

## Мүмкіндіктер

- **3D карта: қалалар.** 12 ортағасырлық қала жер бедерімен бірге көрсетілген. Бағана биіктігі қаланың өмір сүрген ғасырлар санын білдіреді. Картада Ұлы Жібек жолының шартты бағыты мен қалалар хронологиясы бар.
- **3D карта: кесенелер.** 18 кесене төрт өңір бойынша берілген: Оңтүстік, Жетісу–Талас, Ұлытау және Сыр бойы.
- Екі картада да спутник режимі, автоматты «Саяхат», айналдыру, өңір бойынша сүзгі және іздеу бар.
- **3D модель.** Порталды-күмбезді кесененің процедуралық моделі үш режимде көрсетіледі: кірпіш, цифрлық егіз (жүктеме картасы) және LiDAR нүктелер бұлты.
- Цифрлық қайта жаңғыру тізбегі: LiDAR → HBIM → Digital Twins → VR/AR/AI.
- «ArchHeritage VR» концепті: уақыт сызығы бойынша кірпіштен шыны мен металға ауысу.
- Координаталар кестесі (ГИС тізілімі).

## Іске қосу

Сайт статикалық, оны құрастыру (build) қажет емес. Карталар жұмыс істеуі үшін интернет керек.

```bash
python3 -m http.server 8000
```

Содан кейін браузерде http://localhost:8000 ашыңыз. Сайтты GitHub Pages арқылы да жариялауға болады: Settings → Pages → `main` / root.

## Құрылымы

```
index.html            — бет құрылымы
assets/css/style.css  — стильдер (жарық/қараңғы тақырып)
assets/js/data.js     — қалалар мен кесенелердің деректері мен координаталары
assets/js/app.js      — 3D карталар (MapLibre GL), хронология, кесте
assets/js/model.js    — 3D модель (Three.js)
assets/img/           — жоба слайдтары
```
